多雷达与多干扰机智能体对抗功能仿真系统设计与实现
一、项目背景
随着现代电子战环境的日益复杂，雷达面临着来自多方向、多类型的强烈电磁干扰威胁。传统的雷达抗干扰手段往往基于固定规则，难以应对动态的对抗环境。近年来，人工智能（AI）技术在博弈对抗中展现出巨大潜力。本项目旨在通过构建一个可视化的仿真系统，帮助你快速建立雷达系统、电子对抗（ECM）的基本概念，并掌握AI编程在实际工程问题中的应用。
二、任务目标
1. 知识目标：熟悉雷达发射/接收链路、雷达方程、信干噪比（SINR）计算；理解噪声压制干扰、欺骗干扰的基本原理。
2. 技能目标：熟练掌握 Python 编程，熟悉 NumPy 数值计算与 Matplotlib 可视化，了解 PyTorch 深度学习框架及强化学习基本流程。熟悉AI编程能力。
3. 工程目标：完成一个具备人机交互界面的仿真系统，实现从“传统规则对抗”到“AI智能对抗”的演示。
三、工作内容及要求
1. 系统建模（方案设计）
• 场景设定：构建二维平面（X-Y）仿真场景。设定红方（雷达）与蓝方（干扰机）的初始位置、运动速度（可选）。
• 雷达模型：实现雷达核心参数配置（工作频率、发射功率、天线增益、脉冲重复周期、检测门限）。
• 干扰模型：实现干扰机核心参数配置（干扰功率、干扰样式<噪声压制/距离欺骗>、天线增益）。
• 环境模型：实现自由空间路径损耗计算，基于雷达方程和干扰方程计算接收端 SINR。
2. 编码实现（核心功能）
• 基础仿真模块：编写函数计算雷达回波功率与干扰功率，根据 SINR 判决雷达是否检测成功。
• 多实体管理：实现多部雷达与多部干扰机的并发计算逻辑（建议使用面向对象编程 OOP，定义 Radar 类和 Jammer 类）。
• AI 对抗模块（重点）：
  - 引入强化学习（推荐 DQN 算法）。
  - 状态空间 (State)：包含雷达当前频率、干扰机当前功率、当前 SINR 值。
  - 动作空间 (Action)：干扰机调整功率等级、调整干扰频率（模拟瞄频干扰）。
  - 奖励函数 (Reward)：干扰成功得分，浪费功率扣分，引导 AI 学习最优干扰策略。
3. 界面设计（可视化）
• 使用 PyQt5 或 Tkinter 搭建 GUI 界面。
• 态势显示区：实时绘制雷达、干扰机、目标的位置分布（Top-down view）。
• 参数控制区：提供输入框/滑块，用于动态调整雷达和干扰机的参数。
• 数据曲线区：实时绘制 SINR 随时间变化的曲线，对比“传统模式”与“AI模式”下的干扰效果。
四、交付物（产出要求）
1. 仿真系统软件：可直接运行的 Python 程序（.py 文件或打包后的 .exe 文件）。
2. 源代码：结构清晰、注释详尽的源码，需包含 README.md 说明如何运行。
3. 技术报告：
   • 目录
   • 引言（背景与意义）
   • 系统总体设计方案（附架构图）
   • 核心算法详解（雷达方程推导、强化学习模型设计）
   • 实验结果与分析（截图展示仿真效果，分析参数变化对结果的影响，展示AI训练收敛曲线）
   • 总结与展望
   • 参考文献
六、进度安排
两周内完成。
• 查阅资料，熟悉雷达与干扰基础概念，搭建 Python 开发环境，跑通示例代码。
• 完成雷达、干扰机的基础数学模型代码编写，实现 SINR 计算。
• 搭建 GUI 界面，实现单雷达对单干扰机的静态仿真与可视化。
• 扩展为多雷达多干扰机，编写 AI 智能体代码，进行训练与调试。
• 系统联调，优化界面，撰写技术报告。
•查漏补缺，准备汇报 PPT。
七、考核标准
• 基础功能（60%）：系统能正常运行，能正确计算并显示 SINR，界面布局合理。
• AI 模块（20%）：AI 干扰机相比随机干扰机有明显更高的干扰成功率（需提供训练曲线证明）。
• 代码质量与报告（20%）：代码结构清晰，注释规范，报告逻辑严密，图文并茂。
